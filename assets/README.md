# Assets

Marca, ícones e imagens usadas pelo programa, conforme o guia de identidade visual da Cadari.

| Arquivo | Uso |
|---|---|
| `icone.ico` | Ícone da janela e do executável |
| `marca_negativa.png` | Marca na tela de carregamento e no topo da janela |
| `marca_cadari.png` | Marca em policromia, usada no README |
| `tela_abertura.png` | Tela de abertura do PyInstaller, enquanto o executável descompacta |

No código, os arquivos são lidos por `config.recurso("nome.png")`, que funciona no código e no executável.
